# CWLauncher — готовая версия для Windows

Эта ветка содержит полностью собранный CWLauncher со всеми файлами, необходимыми для запуска. Устанавливать JDK или самостоятельно компилировать исходный код не требуется.

## Как скачать и запустить

1. Нажмите **Code → Download ZIP**.
2. Полностью распакуйте ZIP-архив в отдельную папку.
3. Запустите `CWLauncher.exe`.

Не запускайте `CWLauncher.exe` непосредственно из архива и не переносите его отдельно: рядом должны оставаться папки `app`, `runtime`, `jre`, `assets` и остальные файлы.

Исходный код, полное описание проекта и инструкция самостоятельной сборки находятся в ветке [`main`](https://github.com/Difiw/CWLauncherWindows/tree/main).

## Что делает лаунчер

CWLauncher — лаунчер Minecraft Java для сервера Common World. Он устанавливает выбранную версию Minecraft, Fabric и серверные моды, проверяет обновления и запускает игру. По умолчанию используется Minecraft 1.20.1 с Fabric.

Лаунчер также поддерживает локальные и Ely.by-аккаунты, скины, новости, диагностику, восстановление файлов, обновление самого лаунчера и создание локальных Fabric-серверов.

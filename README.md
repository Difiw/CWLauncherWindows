# CWLauncher

Лаунчер Minecraft Java для сервера Common World. Отдельная программа на Java 17: ставит выбранную версию игры, Fabric и моды сервера, при запуске проверяет обновления и запускает Minecraft.

Сервер по умолчанию: `commonworld.pterohost.ru:25965`. Версия игры по умолчанию: Minecraft 1.20.1 с Fabric.

Проект рассчитан на Windows 10/11. Интерфейс доступен на русском и английском языках.

## Скачать

Исходный код можно скачать кнопкой **Code → Download ZIP** на странице репозитория или командой:

```bat
git clone https://github.com/Difiw/CWLauncherWindows.git
```

Для обычного запуска игроку нужен готовый выпуск лаунчера, а для самостоятельной сборки из исходников — JDK 17. Скомпилированные файлы, встроенная Java и временные каталоги сборки намеренно не хранятся в Git.

### Готовый лаунчер для Windows

Полностью собранная версия находится в отдельной ветке [`launcher-ready`](https://github.com/Difiw/CWLauncherWindows/tree/launcher-ready). Чтобы запустить её без самостоятельной сборки:

1. Откройте ветку `launcher-ready`.
2. Нажмите **Code → Download ZIP**.
3. Полностью распакуйте скачанный архив в отдельную папку.
4. Запустите `CWLauncher.exe`.

Не запускайте `.exe` прямо из ZIP-архива: рядом с программой должны оставаться папки `app`, `runtime`, `jre` и остальные файлы готовой сборки.

## Сборка из исходников

Клонируйте репозиторий и откройте его папку в редакторе. Исходники лежат в `src/ru/cw/launcher`. Точка входа: `src/ru/cw/launcher/Main.java`.

Сборка готового `CWLauncher.exe` (нужен JDK 17):

```bat
powershell -ExecutionPolicy Bypass -File build-release.ps1
```

Готовая папка появляется в `FullLauncherCW`. Её нет в git целиком: внутри неё JRE и собранные файлы, их создаёт скрипт. В репозитории сохранён только фон `FullLauncherCW/assets/background/main.png`, чтобы сборка его не затёрла.

Запуск из исходников без упаковки в exe:

```bat
build.cmd
java -cp build ru.cw.launcher.Main
```

## Что делает лаунчер

- При запуске проверяет версию самого лаунчера, новости, список обновлений, версию модов внутри архива `modsCWL.zip` и файлы выбранной версии Minecraft.
- Если моды на сервере новее установленных, кнопка запуска меняется на «Обновить моды». По нажатию папка `mods` очищается, затем в неё ставятся новые моды.
- Если файлы Minecraft устарели, кнопка показывает «Обновить Minecraft»: скачивание начинается по нажатию, после него игра запускается.
- Обновление самого лаунчера вынесено в отдельную кнопку «Обновить лаунчер» и не подменяет кнопку запуска игры.
- Аккаунты Ely.by и локальные. У каждого аккаунта свой скин.
- В комплекте своя Java 17 для Minecraft. Для версий старше 1.17 по-прежнему нужна Java 8.
- Локальные Fabric-серверы доступны из кнопки «Локальные серверы». Лаунчер создаёт чистую папку сервера, не копируя туда файлы игры, и запускает Dedicated Server. При первом запуске Minecraft сам создаёт мир; свои серверные моды можно добавить в папку `mods`.
- Серверы сохраняются в `%APPDATA%\CWLauncher\local-servers.json`, а файлы каждого сервера — в выбранной папке (по умолчанию `%APPDATA%\CWLauncher\servers`). Сервер продолжает работать после закрытия лаунчера и автоматически поднимается при следующем запуске CWLauncher. Остановите его через панель управления, чтобы штатно сохранить мир.
- Для подключения на том же компьютере используйте `localhost:<порт>`, для других игроков — скопированный адрес из панели управления. Для Radmin VPN все игроки должны находиться в одной VPN-сети. Подключение извне зависит от брандмауэра Windows; автоматическая настройка роутера и firewall не выполняется. В сервер включена проверка официальной учётной записи (`online-mode=true`).
- При создании серверной папки требуется явно принять Minecraft EULA. Анимации интерфейса по умолчанию выключены и включаются в настройках.

## Папки

| Путь | Назначение |
| --- | --- |
| `src/ru/cw/launcher` | Исходники лаунчера |
| `tests/SelfCheck.java` | Проверка, которая идёт вместе со сборкой |
| `build-release.ps1` | Сборка `CWLauncher.exe` |
| `icon` | Иконка окна и exe |
| `config/example-config.json` | Пример настроек |

Данные игрока лежат не в папке программы, а в `%APPDATA%\CWLauncher`: настройки, журнал, кэш и скины.

## Доступ к репозиторию

Репозиторий публичный: любой пользователь может скачать исходники или создать собственный fork. Изменять ветки этого репозитория могут только владелец и явно добавленные им участники; остальные пользователи могут предложить изменения через pull request, но не могут самостоятельно записать их в `main` или `branch`.
